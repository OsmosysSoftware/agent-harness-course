# Agent Harness course

Configuring AI coding agents on real projects: the harness, not just the prompt. A course for .NET developers who use Claude Code, Codex or Antigravity as a chat, and need a repo whose rules, skills, reviewers and guards steer any agent.

**Read it:** https://osmosyssoftware.github.io/agent-harness-course/ (or open `index.html` locally). Start with "Before you start".

| Folder | What |
|---|---|
| `lessons/` | 11 lessons, each ending in one exercise |
| `reference/` | Printable reference sheets and glossary |
| `reference-solution/` | StockApi after all 11 lessons, with the full harness |
| `capstone-starter/` | RoomBooking, the fresh repo for the capstone |
| `assets/` | Shared stylesheet, quiz widget, page linter (`python3 assets/check_pages.py`) |

The practice repo lives separately: https://github.com/OsmosysSoftware/agent-harness-practice

Tool behaviour was verified against official docs on 2026-09-30. Anything marked "version-specific" should be re-checked when your tool is newer.
