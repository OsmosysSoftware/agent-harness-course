Claude Code only: the quick view
  • Rules: AGENTS.md in the repo root, and no CLAUDE.md next to it. Nested tests/AGENTS.md loads when a file there is read.
  • Skills: the files live in .agents/skills/<name>/SKILL.md; .claude/skills/<name> is a symlink (a pointer) to that folder. Invoke with /name.
  • Reviewer agents: .claude/agents/<name>.md with name and description.
  • Permission rules and hooks: .claude/settings.json; hook scripts in .claude/hooks/. Deny, then ask, then allow.
  • MCP: .mcp.json; check with claude mcp list.
  • Transcript: /export file.txt for text; raw JSONL under ~/.claude/projects/<project>/.
  • Plan mode: Shift+Tab. On v2.1.283+ new sessions start in auto mode, so commits and launches can run unprompted unless your rules and guards say otherwise.
If you use Codex or Antigravity, the table below is your map; otherwise you can skip those two columns.
